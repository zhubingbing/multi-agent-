# Workbench UI 字体与排版规范

## 基线

Workbench 是生产力型企业中后台，采用清晰、克制、可扫描的系统无衬线字体，不引入额外字体包作为界面依赖。

```css
font-family: -apple-system, BlinkMacSystemFont, "Segoe UI", Roboto,
  "Helvetica Neue", Arial, "Noto Sans", "PingFang SC", "Microsoft YaHei", sans-serif;
```

代码、Run ID、数字和路径使用等宽字体：Consolas、Monaco、JetBrains Mono 或系统等宽字体。

## 字号层级

| 层级 | 字号 | 字重 | 使用场景 |
| --- | ---: | ---: | --- |
| 页面标题 | 24px | 600 | 一级模块页面 |
| 区域标题 | 20px | 600 | 页面核心标题、详情页标题 |
| 卡片标题 | 16px | 600 | Card、对话框和面板标题 |
| 默认正文 | 14px | 400 | 任务、表格、导航、按钮和表单 |
| 辅助文本 | 12px | 400 | 时间、提示、字段说明、状态辅助信息 |
| 最小文字 | 12px | 400 | 中文 Web UI 不得低于此值 |

不使用 9px、10px、11px 作为中文可见信息的默认字号。需要更弱的层级时使用颜色、间距和字重，而不是继续缩小字体。

## 行高与字重

- 默认正文 `line-height: 1.5`，14px 对应约 21px；
- 表格和高密度列表最低使用 1.4；
- 正文使用 400；
- 小标题和重点数据使用 600；
- 不在同一模块混用过多字重；
- 中文长文本必须允许自然换行，不能用过度省略隐藏关键状态。

## 表单

- 输入框、Select 默认高度 36px；
- 表单标签 12px、字重 550；
- Placeholder 使用辅助色，不降低字号；
- 表单组间距 14～18px；
- 主按钮与次按钮统一 34px 高度、8px 圆角；
- 错误、成功和帮助文字均使用至少 12px；
- 表单不使用浏览器原生 prompt/confirm/alert 作为产品交互。

## 列表和详情

- 列表页负责扫描：名称、状态、时间、数量和一个主要操作；
- 详情页负责完整配置、历史和高风险操作；
- 列表与详情不在同一张拥挤卡片中重复展示；
- 状态使用颜色加文字，不只依赖颜色；
- 运行记录必须显示中文状态、触发来源、时间、耗时和失败原因；
- 已删除关联对象显示“对象已删除”，不改变历史运行结果。

## 一致性约束

所有 Workbench 模块共享 `workbench-theme.css` 的字体、字号、控件和颜色基线。模块 CSS 只负责布局和语义状态，不得重新发明一套 9px/10px/11px 字体体系。
